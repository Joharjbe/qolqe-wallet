Hasta aquí la Parte 3. Ahora el consolidado. Como dije al inicio: 335 casos y 30 defectos. Las tres partes no son tres trabajos pegados, pero tampoco comparten todo, y quiero decirlo exacto. API y web comparten los criterios de aceptación, los identificadores CP y la matriz de trazabilidad: un caso de API y uno de web se enlazan al mismo criterio. El rendimiento parte de su propio requerimiento, con sus propios IDs: flujos F, umbrales U y criterios de validez V. Sus flujos se trazan a las mismas historias, por ejemplo el login a HU-N-02, pero no tienen ID CP ni cuentan en los 335 casos: su veredicto es por umbral, no por caso. Lo que sí comparte es la API de soporte, la semilla y el sitio publicado. Voy a ir punto por punto del enunciado. Arriba de cada lámina va la observación de la Entrega 2 que resuelve.
